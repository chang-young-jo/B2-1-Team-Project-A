## 레퍼런스 및 출처
본 프로젝트에서는 종합 쇼핑몰 웹 UI의 화면 구성과 사용자 흐름을 분석하기 위해 SSG.COM(쓱닷컴)과 쿠팡(Coupang)을 레퍼런스로 참고하였습니다.

SSG.COM
출처: https://www.ssg.com/
참고 내용:
종합 쇼핑몰 메인 페이지의 전체적인 정보 구조
검색창과 상단 메뉴 구성
이벤트 및 프로모션 배너 배치
추천 상품 및 쇼핑 콘텐츠 배치 방식

쿠팡(Coupang)
출처: https://www.coupang.com/
참고 내용:
상품 검색 결과 페이지의 정보 구성
상품 목록의 그리드 배치 방식
상품 이미지, 상품명, 가격 정보 표시 방식
상품 상세 페이지의 이미지, 가격, 옵션 선택 등 정보 구조

SSG.COM과 쿠팡의 화면을 그대로 복제하거나 캡처하여 최종 결과물로 사용한 것이 아니라, 종합 쇼핑몰의 일반적인 UI 구조와 화면 흐름을 분석하기 위한 참고 자료로 활용하였습니다.

최종 UI 디자인 이미지는 Google Gemini Nano Banana를 이용하여 새롭게 생성하였으며, 생성 이후 한글 오탈자와 부자연스러운 요소를 수정하고 Figma를 활용하여 프로토타입으로 구성하였습니다.


## 피그마 프로젝트 최종본

## 1. 메인 페이지 실행 --> 3초 지연 후 팝업창 열림(오디세이 홍보)
 - 오디세이 홍보 팝업창 우측 상단 X 박스 클릭하여 팝업창 제거
 - 메인페이지 상단 (남녀 커플 래쉬가드) 검색 클릭 --> 목차 페이지로 연결

## 2. 목차 페이지
 - 목차페이지에서 첫번째 제품 클릭 --> 상세 페이지로 연결
 
## 3. 상세 페이지
 - 상세페이지에서 왼쪽 상단 스타 쇼핑몰 로고 클릭 --> 메인 페이지로 연결
